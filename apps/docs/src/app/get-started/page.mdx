# 설치와 사용

```bash
npm install @nui-kit/react lucide-react
```

peer dependency 는 `react` · `react-dom` · `lucide-react` 셋이다. `lucide-react` 는 아이콘
세트이고, 소비자 프로젝트와 한 벌을 나눠 써야 한 화면의 아이콘이 한 세트가 된다. `next` 와
`react-hook-form` 은 optional 이다 — `next` 는 `ButtonLink`(`@nui-kit/react/next`)를,
`react-hook-form` 은 RHF 래퍼를 쓸 때 설치한다. Node 는 18.18.0 이상이다.

## 어디서 쓸 수 있나

| 환경 | 상태 |
| --- | --- |
| Next.js App Router | 이 문서 사이트와 검사가 여기서 돈다 |
| Next.js Pages Router | 같은 `next/link` · 같은 클라이언트 API 라 막지 않는다. 전역 CSS 는 `_app` 에서 불러온다 |
| 순수 React (Vite 등) | 배럴과 컴포넌트 서브패스는 `next` 없이 설치 · 타입체크된다. `ButtonLink` 만 Next 전용이다. 번들러가 `"use client"` 지시어에 경고를 낼 수 있는데 무시해도 된다 |

## 스타일 불러오기

CSS 는 JS 에 포함되지 않는다. 스타일을 적용하려면 직접 import 한다.

```ts
import "@nui-kit/react/styles/index.css";
```

일부 컴포넌트만 쓴다면 파일을 나눠 가져온다. `tokens.css` 는 나머지 전부가 참조하므로
한 번은 넣는다. CSS 파일 이름은 서브패스 이름과 같다.

```ts
import "@nui-kit/react/styles/tokens.css";
import "@nui-kit/react/styles/button.css";
```

### preflight

기본 배포에 reset 이 없다. 컴포넌트가 UA 기본 스타일을 스스로 정규화하므로 대부분
필요하지 않다. reset 이 전혀 없는 프로젝트라면 그때 추가한다.

```ts
import "@nui-kit/react/styles/preflight.css";
```

## 루트 layout

앱 루트에서 한 번 정한다. 스타일 · 브랜드 색 · Host 셋이 여기 모인다.

```tsx
// app/layout.tsx
import "@nui-kit/react/styles/index.css";
import "@nui-kit/react/styles/themes/preset-42.css"; // 브랜드 색 — 없어도 된다
import { PopupHost, ToastHost } from "@nui-kit/react";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="ko">
      <body>
        <PopupHost>
          <ToastHost>{children}</ToastHost>
        </PopupHost>
      </body>
    </html>
  );
}
```

### Host

`useToast()` · `useAlert()` · `useConfirm()` 같은 명령형 훅은 `PopupHost` · `ToastHost` 안에서만
뜬다. Host 가 없으면 에러 없이 조용히 렌더되지 않는다. `<LayerPopup open={…} />` 처럼 선언형으로
직접 렌더할 때는 Host 가 없어도 된다. 상세는 [Popup 개요](/components/popup) 에 있다.

### 브랜드 색

준비된 프리셋은 번호의 CSS 를 한 줄 불러온다. 목록에 없는 색은 명령으로 만든다 —
`./nui-theme.css` 가 생기고 루트 layout 에 import 한 줄이 들어간다.

```bash
npx nui-theme --accent "#b1002a"   # 목록에 없는 색
npx nui-theme --preset 42          # 프리셋도 같은 명령. 패키지에 든 파일을 복사한다
```

번호와 미리보기, 명령이 받지 않는 색은 [브랜드 색 고르기](/brand-colors) 에 있다.

### 다크

OS 가 다크면 아무 설정 없이 다크로 그려진다. `<html data-theme="dark">` 를 주면 그것이 이기고,
`"light"` 를 주면 OS 가 다크여도 라이트를 유지한다. 순서와 바뀌는 것은 [색](/foundations/color) 에 있다.

## 컴포넌트 가져오기

```tsx
// 배럴
import { Button, Field, Textfield } from "@nui-kit/react";

// 서브패스 — 번들 최소화
import { Button } from "@nui-kit/react/button";

// react-hook-form 래퍼
import { RHFTextfield } from "@nui-kit/react/rhf";

// Next.js 전용 — next/link 를 쓰는 ButtonLink
import { ButtonLink } from "@nui-kit/react/next";
```

배럴과 서브패스 중 어느 쪽으로 가져와도 React Context 를 공유한다. `Field` 와
`Textfield` 를 다른 경로에서 가져와도 연동이 끊기지 않는다.

`Search` 와 `Password` 는 서브패스가 따로 없다. `Textfield` 계열이라 `textfield`
서브패스에 함께 들어 있고 CSS 도 `textfield.css` 하나로 끝난다.

| 서브패스      | 들어 있는 것                                                                                                                        |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `/button`     | `Button` `IconButton` `ButtonGroup` `ButtonGroupItem`                                                                               |
| `/next`       | `ButtonLink` — Next.js 전용                                                                                                          |
| `/field`      | `Field` `FieldItem` `FieldGrid` `FieldHeader` `FieldLabel` `FieldMessage` `useFieldContext` `getMergedAriaIds`                      |
| `/textfield`  | `Textfield` `Search` `Password` `Message`                                                                                           |
| `/textarea`   | `Textarea`                                                                                                                          |
| `/checkbox`   | `Checkbox` `CheckboxGroup` `useCheckboxGroupContext`                                                                                |
| `/radio`      | `Radio` `RadioGroup` `useRadioGroupContext`                                                                                         |
| `/switch`     | `Switch`                                                                                                                            |
| `/popup`      | `Alert` `Confirm` `LayerPopup` `BottomSheet` `FullPopup` `PopupHost` · 여는 훅 5종(`useAlert` 등) · `usePopupStack` `usePopupStore` |
| `/toast`      | `Toast` `ToastHost` `useToast` `useToastStack` `useToastStore`                                                                      |
| `/tooltip`    | `Tooltip`                                                                                                                           |
| `/accordion`  | `Accordion` `AccordionItem` `AccordionButton` `AccordionHead` `AccordionPanel` `useAccordionContext`                                |
| `/select`     | `Select` `MultiSelect`                                                                                                              |
| `/datepicker` | `Datepicker` `DateRangePicker` `DateMultiplePicker` · 값 포맷 함수 3종(`formatSingleDateValue` 등)                                  |
| `/icon`       | `Icon` · 프리셋 11종(`DelIcon` `CloseIcon` `SearchIcon` `SpinnerIcon` 등)                                                           |
| `/rhf`        | RHF 래퍼 전부                                                                                                                       |

## Server Component

모든 컴포넌트가 `"use client"` 로 배포된다. App Router 는 이 지시어로 서버/클라이언트 경계를
만들고, Pages Router 와 순수 React 번들러는 무시한다. Server Component 안에서는
`Field.Label` 같은 dot notation 대신 `FieldLabel` 같은 named export 를 쓴다 —
타입 검사와 빌드는 통과하고 렌더할 때만 깨지는 종류다.

대응표와 이유는 [오염시키지 않는다](/design-system/isolation) 에 있다.

## 커스터마이징

치수와 모양은 컴포넌트별 CSS 변수로 바꾼다. 색은 화면 전체를 브랜드 색 하나로 바꾸거나
(프리셋 번호 또는 `npx nui-theme --accent`), 한 컴포넌트만 `className` 으로 직접 지정한다.
컴포넌트별 색 변수는 없다.

- [커스터마이징](/foundations/customizing) — 공개 변수 전체 목록과 막아둔 것
- [브랜드 색 고르기](/brand-colors) — 프리셋 185색과 목록에 없는 색을 만드는 명령

`--nui-_` 로 시작하는 변수는 내부 배선이다. 덮어쓰면 variant 가 깨진다.
