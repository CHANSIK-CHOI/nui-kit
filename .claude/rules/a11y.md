# 접근성 규칙

컴포넌트 라이브러리의 접근성은 **소비자가 고칠 수 없다.** 여기서 보장해야 한다.

## 1. id 연결은 Field 가 소유한다

`Field` 가 `useId()` 로 만든 `inputId` 를 Context 로 내려보내고,
`Field.Label` 의 `htmlFor` 와 컨트롤의 `id` 가 같은 값을 쓴다.
컨트롤은 자기 `id` prop → Context → 자체 생성 순으로 해석한다.

## 2. `aria-describedby` 는 합쳐서 넘긴다

description / message 는 마운트 시 Context 에 자기 id 를 등록하고 언마운트 시 해제한다.
컨트롤은 `getMergedAriaIds(사용자값, ...contextIds, 자체메시지id)` 로 중복 없이 합친다.
직접 문자열을 이어붙이지 않는다.

## 3. 에러 상태

- 에러면 컨트롤에 `aria-invalid={true}` (거짓일 때는 속성 자체를 생략)
- 에러 메시지는 `aria-describedby` 로 연결되어야 한다
- **색만으로 에러를 표현하지 않는다** — 아이콘 + 텍스트를 함께 제공한다

## 4. 아이콘 전용 컨트롤에는 접근 이름을 붙인다

```tsx
<button ...>
  <DelIcon />
  <span className={px("sr-only")}>내용 지우기</span>
</button>
```

`Icon` 은 `title` 이 없으면 `aria-hidden`, 있으면 `role="img"` + `<title>` 이다.
장식용 아이콘에 접근 이름을 중복으로 넣지 않는다.

## 5. 포커스

- `:focus-visible` 로만 링을 그린다 (`:focus` 로 마우스 클릭까지 잡지 않는다)
- 포커스 링은 `--nui-focus-color` / `--nui-focus-ring-width` 토큰을 쓴다
- `outline: none` 을 쓸 때는 반드시 대체 표시(테두리·그림자)를 준다

## 6. 모션

`prefers-reduced-motion: reduce` 에서 duration 토큰이 `1ms` 로 무력화된다.
컴포넌트에서 duration 을 하드코딩하면 이 장치를 우회하게 되므로
반드시 `--nui-duration-*` 토큰이나 `motion()` 믹스인을 쓴다.

## 7. 시맨틱

- 누르는 것은 `<button type="button">`, 이동하는 것은 `<a>` / `next/link`
- 그룹 컨트롤(체크박스·라디오 묶음)은 `fieldset` + `legend` 또는 `role="group"` + 접근 이름
- placeholder 를 라벨 대용으로 쓰지 않는다
