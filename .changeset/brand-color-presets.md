브랜드 색을 바꾸는 방법이 생겼습니다. **준비된 185색 중 하나를 고르면 화면 전체가 그 색에
맞춰 다시 만들어집니다** — 버튼·입력창·선택 컨트롤은 물론 회색과 포커스 링까지 따라옵니다.

```bash
npm run color:generate -- --preset 42
```

```css
@import "@nui-kit/react/styles/index.css";
@import "./nui-theme.css";   /* 생성된 파일. 라이브러리 CSS 뒤에 */
```

고를 수 있는 색은 문서 사이트의 **브랜드 색 고르기** 페이지에서 미리 봅니다. 색깔별로
나뉘어 있고, 카드마다 12단계·회색·반투명·글자색과 대비 수치가 함께 나옵니다.

**색은 Radix 공식 생성기가 만듭니다**

색 스케일을 우리가 직접 계산하지 않습니다. Radix 가 공개한 생성기(MIT)를 그대로 씁니다.
25개 참조 곡선 중 고른 색에 가장 가까운 것을 골라 쓰는 방식이라, **고른 색이 다르면
결과도 다릅니다.** 9번 단계 재조정·글자색 계산·버튼 hover 색·채도 제한·반투명 역산이
전부 그 안에 들어 있습니다.

현재 기본 색(`#01796f`)으로 돌리면 지금 배포되는 값이 **한 글자도 다르지 않게** 재현됩니다.

**고른 색이 그대로 나오지 않을 수 있습니다**

185색 중 105색은 고른 색이 9번 단계에 그대로 들어갑니다. 나머지 80색은 **너무 밝아서
어둡게 낮춥니다.** 9번은 버튼처럼 색으로 꽉 찬 면의 배경이라, 밝으면 그 위에 흰 글자도
검은 글자도 읽히지 않기 때문입니다. 밝기가 76 언저리를 넘으면 그렇게 되고, 미리보기
페이지의 카드에 그 사실을 적어둡니다.

**대비 기준은 자리마다 다릅니다**

| 자리 | 기준 |
| --- | --- |
| 9번 배경 위 글자 | 3:1 — 채워진 면 위의 라벨 |
| 11번 저대비 본문 | 4:1 |
| 12번 고대비 본문 | 4.5:1 (WCAG AA) |

9번에 AA(4.5:1)를 요구하면 **Radix 공식 23색 중 5색만 통과합니다.** 채워진 면 위의
라벨은 WCAG 가 UI 구성요소·큰 글자에 인정하는 3:1 범위에 듭니다. 긴 글에 쓰는
12번은 AA 를 그대로 지킵니다.

**`presets.json` 이 패키지에 포함됩니다**

고를 수 있는 185색의 목록입니다. Figma 커뮤니티 팔레트 400색에서 출발해 색깔을 믿을 수
없는 색과 글자가 읽히지 않는 색을 걸러낸 것이고, 목록에 올리기 전에 실제로 만들어보고
검사했습니다. **소비자가 무엇을 고르든 이미 확인된 색입니다.**
