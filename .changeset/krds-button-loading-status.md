`Button` · `IconButton` 의 **로딩 시작이 포커스 밖에서도 들립니다.** KRDS 가이드 595쪽 02 —
스피너의 상태를 `aria-live` 로 알리라는 기준입니다.

예전에는 `aria-describedby` 로만 연결돼 있어 **포커스가 그 버튼에 있을 때만** 읽혔습니다.
폼에서 Enter 로 제출해 포커스가 입력창에 남아 있으면 아무 말도 없었습니다.

- 문구(`loadingLabel`, 기본 "처리 중")가 `body` 의 공용 `role="status"` 영역
  (`#nui-status-root`, 화면 밖)에 놓입니다. 버튼 **안**의 live 영역은 보조기술이 이름 변경으로
  처리해 무시하기 때문입니다
- 같은 문구를 `aria-describedby` 가 계속 가리키므로 포커스가 버튼에 있을 때의 동작은
  그대로입니다
- 팝업 안 버튼도 알려집니다
- **완료는 알리지 않습니다.** 버튼은 결과를 모릅니다 — `isLoading` 이 내려간 것이 성공인지
  실패인지 알 수 없어서, "완료"라고 말하면 실패했을 때 거짓말이 됩니다. 결과 알림은
  `Toast` 나 에러 메시지 몫입니다

새 prop 은 없습니다. 마크업에서는 버튼 안에 있던 sr-only 문구가 사라지고 `body` 로 옮겨갑니다.
