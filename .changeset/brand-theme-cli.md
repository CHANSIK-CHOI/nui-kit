목록에 없는 브랜드 색을 명령 하나로 만들 수 있습니다.

```bash
npx nui-theme --accent "#b1002a"   # ./nui-theme.css 가 생깁니다
npx nui-theme --preset 42          # 프리셋도 같은 명령으로 파일로 받습니다
```

```tsx
import "@nui-kit/react/styles/index.css";
import "./nui-theme.css";
```

설치돼 있으면 바로 됩니다. 의존성이 더 깔리지 않습니다. 생성기가 패키지 안에 들어 있어서 tarball 이 약 180 kB 늡니다.

프리셋 번호를 주면 패키지에 든 파일을 그대로 복사합니다. 문서 사이트에서 본 색과 같습니다. 임의 색을 주면 프리셋과 같은 규칙으로 나머지 색을 계산합니다.

회색에 가까운 색은 받지 않습니다. 화면 전체가 엉뚱한 색조로 물들기 때문입니다. 채워진 버튼 위 글자 대비가 기준에 못 미치면 파일은 만들되 수치와 함께 알립니다. 같은 이름의 파일이 있으면 덮어쓰지 않습니다. `--force` 를 주면 덮어씁니다.
