`DateRangePicker` 로 하루짜리 기간을 만들 수 있습니다.

**⚠️ BREAKING**

`dayPickerProps.min` 의 기본값 `1` 을 없앴습니다. 이름과 달리 **최소 일수로는 아무
역할도 하지 않고**(react-day-picker 는 `min > 1` 일 때만 검사합니다), 유일한 효과가
같은 날을 다시 눌렀을 때 하루 기간을 만드는 대신 **선택을 통째로 비우는 것**이었습니다.

```
전:  9월 15일 클릭 → "2026.09.15 - "  → 다시 클릭 → ""        (초기화됩니다)
후:  9월 15일 클릭 → "2026.09.15 - "  → 다시 클릭 → "2026.09.15 - 2026.09.15"
```

"9월 1일 하루" 를 기간으로 받으려면 `min: 0` 을 명시해야 한다는 사실을 알 방법이
없었습니다.

이전처럼 하루짜리를 막으려면 최소 일수를 직접 주세요. `2` 이상부터 실제로 검사됩니다.

```tsx
<DateRangePicker dayPickerProps={{ min: 2 }} />
```
