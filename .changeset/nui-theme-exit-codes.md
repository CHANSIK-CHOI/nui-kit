`nui-theme` 의 종료 코드와 출력 자리를 공개 API 로 정했습니다(README 「버전 정책」). 성공은 `0`, 이 입력으로는 만들 수 없으면 `1`, 파일을 읽거나 쓰지 못하면 `2` 입니다. 결과는 stdout 에, 오류와 경고는 stderr 에 씁니다.

**BREAKING**(좁음) — 아래 두 경우의 종료 코드가 `1` 에서 `2` 로 바뀝니다. 종료 코드를 `1` 과 정확히 비교하던 스크립트만 해당하고, 「0 이 아니면 실패」로 보던 스크립트는 그대로 동작합니다. 옮기려면 `2` 도 실패로 받거나 「0 이 아님」으로 봅니다.

- `--out` 폴더가 없거나 쓸 수 없을 때. 0.2.x 는 Node 의 스택을 찍고 끝났고, 이제 한 줄 까닭을 찍습니다
- 패키지 안의 `styles/themes` 를 찾지 못할 때(설치가 깨짐)

함께 바뀐 것.

- 인자 없이 부르면 사용법을 stderr 에 찍습니다(종료 코드는 그대로 `1`). `--help` 는 그대로 stdout 과 `0` 입니다
- 루트 layout 을 찾지 못했거나 여럿이라 import 를 넣지 않았다는 안내를 stderr 에 찍습니다(종료 코드는 그대로 `0`)
- 모르는 옵션은 지금처럼 무시하되 stderr 에 알립니다. 오타 난 `--no-aply` 가 조용히 layout 을 고치는 일을 막으려는 것입니다
- layout 을 읽거나 쓸 수 없으면 테마 파일을 쓰기 전에 멈추고 `2` 로 끝납니다. 0.2.x 는 테마 파일을 쓴 뒤 스택을 찍고 끝났습니다
